# 视频讲解脚本框架
## 《AI订阅与Harness工具生态对比分析》配套录制脚本

> 用途：照着 PPT（共 24 页）录讲解视频。每页给出【口播要点】+【转场提示】，口语化表达可自行发挥，数据点照读即可。
> 建议总时长：15–18 分钟（封面目录 1 分钟、核心框架 2 分钟、三个梯队 9–10 分钟、办公赛道 1.5 分钟、总结 2 分钟）。

---

## 〇、开场钩子（P1 封面，约 40 秒）

- 「2026 年了，市面上 AI 编程订阅已经有二十多款，价格从 1 美元到 300 美元不等。但我今天要告诉你一个反直觉的结论：**单看订阅价格选产品，几乎必踩坑**。」
- 「因为这一年行业最大的变化是——各家都在把自己的模型和自己的工具焊死。订阅只是入场券，Harness 工具才是主战场。」
- 「这期视频我们按三个梯队 + 一条办公赛道，把 18 款产品全部拆一遍，每个产品只回答一个问题：**这份订阅和它自家工具绑在一起，到底值不值？**」

【转场】「先看目录，我们按梯队一层层往下拆。」

---

## 一、目录 + 核心框架（P2–P4，约 2 分钟）

### P2 目录（20 秒）
- 「结构很简单：先讲分析框架，然后第一梯队四个国际头部、第二梯队七个国产主力加 Gemini、第三梯队五个轻量玩家，办公类单独成章，最后一页大表收尾。」

### P3 核心观点（60 秒）★ 全片最重要的一页
- 「记住这个公式：**订阅 × 自家 Harness 工具 = 真实战力**。三个证据：」
- 「第一，工具锁模型——Cursor 的 Composer 2.5 根本没有公开 API，离开 Cursor 你就调不到；xAI 的 Grok Build 只跑自家 Grok。」
- 「第二，订阅锁工具——Codex 压根没有单独售价，直接焊死在 ChatGPT 会员里；智谱更直接，套餐协议写明只能在官方白名单工具里用，违规触发风控。2026 年 1 月 Anthropic 封杀第三方工具复用 Claude 订阅，这件事标志着闭环从趋势变成事实。」
- 「第三，联合优化出性能——豆包 Seed-Code 和 TRAE 联调后 SWE-Bench 78.8% 直接登顶；Kimi K3 配自家 Kimi Code，长任务成功率 45.8%，同一个工具换旧模型只剩 7.2%，**六倍差距**。」

【转场】「所以今天的对比不按价格排，按『绑定深度』排。先看全景地图。」

### P4 梯队全景（30 秒）
- 「第一梯队拼模型和工具的联合优化深度；第二梯队拼性价比加官方工具白名单；第三梯队拼单点长板。办公类 Agent 是另一条赛道——它产出的是 PPT 和会议纪要，不是代码，最后单独讲。」

## 二、第一梯队：顶级国际与头部（P5–P9，约 3 分钟）

### P5 章节页（10 秒）
- 「第一梯队四家，共同点：模型全球头部，订阅和工具焊得最死。」

### P6 Cloud Cursor（50 秒）
- 「Cursor，20 美元起步，Ultra 要到 200。它最狠的设计是双模型池：自家 Composer 2.5 用量管够、成本只有 Opus 的十分之一；你要用 Claude、GPT 这些第三方模型，按 API 价计，额度烧得飞快。」
- 「工具侧它是触发面最广的：桌面 IDE、CLI、云端 Agent，甚至 Slack 里 @一下、GitHub PR 里留个言都能唤起一个云端 Agent。」
- 「一句话点评：**20 美元买的不是模型额度，是 Composer 模型池加云端 Agent 网络的入场券**。你在 Cursor 里只用第三方模型，等于把订阅用成了转售商。」

### P7 OpenCode Go（40 秒）
- 「opencode 是第一梯队里唯一的『反闭环』玩家：工具开源免费，Go 订阅 10 美元一个月，模型中立、75 家提供商随便路由，还能本地跑 Ollama 零成本。」
- 「但注意，它也是闭环趋势的受害者——Anthropic 封杀之后，Claude 订阅在 opencode 里已经用不了了。它适合什么人？不想被任何一家绑死的人。**它是逃生舱，代价是放弃订阅补贴价。**」

### P8 SuperGrok（40 秒）
- 「xAI 的 SuperGrok 30 美元起步，Heavy 档 300 美元——但 Heavy 送你 200 美元的 Cursor Ultra，这是『联盟式闭环』的玩法。」
- 「自家工具 Grok Build 架构很有想法，8 个并行子 Agent 各自跑独立 worktree。但它的编程能力落后 Claude 半个身位，而且最初只有 300 美元档才碰得到完整体验。xAI 的打法是**模型低价铺路、订阅收网**。」

### P9 Codex × ChatGPT（50 秒）
- 「OpenAI 把『订阅即入口』做到极致：Codex 没有独立售价，每一档 ChatGPT 会员都内含 Codex，免费档都能体验。GPT-5.6 Sol 在自家 Codex 环境里跑出 Coding Agent Index 80 分，全球第一。」
- 「工具覆盖面也最广：网页云任务、开源 CLI、IDE 插件、iOS、GitHub 委派，本地云端共享一个额度池。」
- 「一句话：**这份 20 美元会员费，本质就是 Codex 的门票。**」

【转场】「国际头部看完，回头看你最关心的国产主力——性价比的故事开始了。」

## 三、第二梯队：国产主力 + 部分国际（P10–P17，约 4.5 分钟）

### P10 章节页（10 秒）
- 「第二梯队七家：模型追平国际，价格是三分之一到一半，绑定方式变成『官方工具白名单』。」

### P11 Kimi × Kimi Code（45 秒）
- 「Kimi 会员 49 到 699 元五档。K3 模型 1M 上下文、Program Bench 77.8 基本打平 GPT-5.6 Sol。配套 Kimi Code 是国产 CLI 里成熟度最高的。」
- 「最强绑定证据就是刚才那个数据：K3 加 Kimi Code 长任务 45.8%，同工具换旧模型只有 7.2%。**49 到 699 的阶梯，本质是 Kimi Code 里 Agent 并行数和上下文长度的解锁钥匙。**注意 7 月起算力紧张，新订阅一度要排队。」

### P12 智谱 × Z Code（45 秒）
- 「智谱 GLM Coding Plan，7 月改积分制后涨价不少，Lite 现售 94 块 4。GLM-5.3 拿了 Terminal-Bench 开源第一。」
- 「它是『订阅锁工具』最诚实的样本：官方白名单 20 多款工具——Claude Code、Cursor 都能用——但出了白名单就触发风控。定位很直白：**三分之一成本、三倍用量的 Claude 平替**。自家 Z Code 和 GLM-5.2 深度联调，还能手机远程指挥。」

### P13 MiniMax（35 秒）
- 「MiniMax Token Plan 49 元起，全场唯一『一个订阅覆盖文本图像语音视频全模态』。M3 模型 SWE-Bench Pro 59%，API 价格在国际同档里极低。」
- 「绑定细节很妙：在自家 MiniMax Code 里**免配 API Key、订阅额度即插即用**；出了自家工具，就得手动接。短板是下午三点到五点半高峰期动态限流。」

### P14 DeepSeek API（35 秒）
- 「DeepSeek 是全场唯一没有订阅可买的：C 端免费，B 端纯 API 按量，现在还搞峰谷电价——避开北京时间的白天高峰，价格直接腰斩。缓存命中折扣是各家最深的。」
- 「它没有官方工具，定位就是** Harness 自由的燃料供应商**：工具你随便挑，但没有任何工具为它深度联调。适合批量推理和自托管。」

### P15 千问 Token Plan（35 秒）
- 「阿里有三条线：百炼 Coding Plan、Token Plan、Qoder IDE 全家桶。Token Plan 限时 39 元起，150 多个模型随便切，夜间 Qwen3.8-Max 打五折。」
- 「它的闭环不是锁工具，是**锁云平台**——你买的是整个百炼控制台和阿里云账号体系的分量。短板是三条产品线有割裂感。」

### P16 火山引擎双 Plan（50 秒）★ 国产绑定最强样板
- 「字节火山引擎，Coding Plan 40 元起步、首两月二五折只要 9 块 9；Agent Plan 是业界第一个 Agent 专用套餐包，实测 Medium 档单百万 token 成本约 1 块钱。」
- 「但重点是这个：**Doubao-Seed-Code 和自家 IDE「TRAE」深度联调后，SWE-Bench 78.8% 登顶 SOTA**，而且豆包的编程能力不单独卖，只通过 Coding Plan 和 TRAE 提供。这是『模型+工具联调』的官方样板——78.8 这个分数，只存在于 TRAE 里。」

### P17 Gemini AI Pro（35 秒）
- 「Google 的 AI Pro 19.99 美元，打法是用免费的 Gemini CLI 慷慨额度引流，Antigravity IDE 的优先权锁在 Ultra 档收网。订阅里还塞了 2TB 存储和 YouTube Premium——**它卖的不只是模型，是整个 Google 生态的会员。**短板：国内支付门槛高。」

【转场】「主力阵容看完，最后是五个另辟蹊径的轻量玩家。」

- 「办公赛道的结论很粗暴：**没有跨生态赢家——你的公司在哪个 IM 里，就买哪家的订阅。办公赛道的 Harness，就是 IM 本身。**」

## 七、录制与制作提示

### 节奏与呈现
- 每个产品页遵循「价格 → 模型 → 工具 → 一句点评」四拍节奏，点评句放慢语速、加重语气
- P3（核心观点）和 P23（大表）是唯二需要观众暂停细看的页面，口播中明确说出「暂停一下」
- 页底铜色点评条是视觉记忆点，讲到时可以用鼠标/光标圈出

### 金句库（可做字幕高亮/短视频切片）
1. 订阅只是入场券，Harness 工具才是主战场
2. 同一个工具换模型，战力差 6 倍
3. 78.8% 这个分数，只存在于 TRAE 里
4. Codex 没有售价——ChatGPT 会员本身就是门票
5. 办公赛道的 Harness，就是 IM 本身
6. 先选工具，再买订阅，顺序别反了
